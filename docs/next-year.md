ระดับสูงใช้ `Speed_motor(200)`, `Set_kp(30)`, `Set_kp_gain(0)`

## ปัญหา: ใช้ความเร็วสุดไม่ได้
1. ส่ายทางตรง
2. เห็นโค้งเป็นแยก แล้วหันไปเช็คกระป๋อง
3. เลยแยก

## แนวแก้ที่ร่างไว้ (ยังไม่ได้ใส่ในโค้ด ยังไม่ได้ลองกับหุ่น)
ลองทีละข้อตามลำดับ

### 1. ส่ายทางตรง: คิด D ตามเวลา
`D` เดิมไม่เป็น 0 แค่รอบ loop เดียว และ `Kd = 1` น้อยเกินไป
```cpp
#define D_MS 15
float err_old = 0;
unsigned long t_d = 0;

// ใน calculate_pid() แทน D = error - previous_error;
if (millis() - t_d >= D_MS) {
  D = error - err_old;
  err_old = error;
  t_d = millis();
}
// ใน PID_speed_reset()
err_old = 0;
// ใน Mission()
Kd = 10;   // เพิ่มทีละ 5
```

### 2. โค้งแรง: ลดความเร็วตาม error
```cpp
#define CURVE_SLOW 10
// ใน motor_control()
int base = ramp(initial_motor_speed, millis() - t_go) - CURVE_SLOW * abs(error);
```
มีผลกับ `cross_down()` และ `push()` ด้วย

### 3. โค้งหลอกเป็นแยก
`#define WIDE_R 0` (อาจพลาดแยกบนโค้งขวา) ถ้ายังหลอกให้ลด `LATCH_MS` จาก 30 เป็น 15

### 4. เลยแยก: เบรกก่อนข้าม
```cpp
#define BRAKE_MS 40
// ต้น cross_down()
drive_motor(1, 1, 1, 1);
delay(BRAKE_MS);
```
ต้องจูน `time_cross` ใหม่ และถ้าอาการคือ "ไม่เจอแยก" ข้อนี้ไม่ช่วย

## สิ่งที่ต้องทำก่อน: ultrasonic สองข้าง
ความเร็วอย่างเดียวสู้ทีมที่ติด sensor ข้างไม่ได้ (เช็คกติกาปีหน้าก่อน)

สนาม Layout C: 12 แยก, เส้นแยก 15 เส้น ถ้ากระป๋อง 8 ใบ (ตามรูปสนามที่เคยถ่าย) จะว่าง 7 เส้น
ตอนนี้เช็คเส้นว่างเสียราว 3 วินาทีต่อแยก (ค่าเฉลี่ยจากที่สังเกต) รวมราว 21 วินาที

ลำดับงาน
1. ติด ultrasonic สองข้าง
2. ให้เส้นแยกว่างวิ่งผ่านโดยไม่หยุด
3. แก้โค้งหลอกกับอาการส่าย
4. ค่อยเพิ่มความเร็ว

### การต่อสาย (ยังไม่ได้ลอง)
- ซ้าย: Echo D9, ขวา: Echo D10
- Trig: ซ้ายใช้ D11 ร่วมกับตัวหน้าได้ ขวาแยกไป A5 แล้วสลับยิงซ้ายขวา กันคลื่นกวนกัน
- ตำแหน่งติดต้องลองจริง: แนวเพลาล้อ หรือใกล้แถว sensor เส้น

### ทดสอบก่อนเขียนเส้นทาง
ติดตัวเดียว วิ่งผ่านกระป๋อง 10 รอบที่ 200 และ 255 แล้วบี๊บเมื่อเจอ ต้องเจอครบทุกรอบ
- ขณะวิ่งอย่าใช้ `ping_can()` (มี delay) ให้ยิงครั้งเดียวต่อรอบ เจอสัก 2 ครั้งค่อยนับ
- `pulseIn()` บล็อกได้ถึง 6 ms ถ้าวิ่งตามเส้นสะดุด ให้ลด timeout หรือใช้ interrupt
