คู่มือหุ่นเดินตามเส้น TRT

ทุกคำสั่งใน Mission() อธิบายเป็นภาษาไทย พร้อมหุ่นจำลองที่รันโค้ดชุดเดียวกับบนบอร์ด ให้เห็นว่าหุ่นไปหยุดตรงไหน

กำลังรัน: - เปิดสนามทดลอง ดาวน์โหลดโค้ดหุ่น
START
หุ่นทำงานยังไง วิธี calibrate ตาของหุ่น: เซนเซอร์ 5 ตัว วิ่งตามเส้นยังไง คำสั่งทั้งหมด ตั้งค่า วิ่งตามเส้น ข้ามแยก ดันกระป๋อง เลี้ยว หยุด ระดับสูง (ultrasonic) ใหม่ หาค่าล้อให้วิ่งตรง เคลื่อนที่ไม่ดูเส้น ถอยหลัง (ไม่แนะนำ) สนามทดลอง เคล็ดลับและกับดัก ตารางสรุป

หุ่นทำงานยังไง

เปิดเครื่องแล้วหุ่นทำตามลำดับนี้ครั้งเดียว

  1. บี๊บสามเสียง พร้อมแล้ว
  2. รอกดปุ่ม กดปุ่มเริ่ม แล้วหุ่นบี๊บอีกที
  3. วิ่งตาม Mission() คือเส้นทางที่เราเขียนไว้ในไฟล์ Mission.ino
  4. หยุด จบรอบ

วิธี calibrate (สอนหุ่นให้รู้จักขาว/ดำ)

ทำเมื่อไหร่: ก่อนแข่ง ย้ายสนาม หรือไฟในห้องเปลี่ยน ถ้าหุ่นวิ่งหลุดเส้นบ่อยผิดปกติ ลอง calibrate ใหม่ก่อน

  1. วางหุ่นคร่อมเส้นดำ บนสนามจริง ให้เส้นอยู่ใต้กลางหุ่น
  2. กดปุ่มค้างไว้ แล้วเปิดเครื่อง ได้ยินบี๊บ 1 ครั้ง
  3. ปล่อยปุ่ม แล้วเอามือออก อย่าแตะหุ่น
  4. หุ่นหมุนซ้ายขวาเอง 3 วินาที เพื่อให้เซนเซอร์ทุกตัวเห็นทั้งขาวและดำ
  5. ฟังเสียง
    บี๊บสั้น 3 ครั้ง = สำเร็จ บันทึกแล้ว
    เสียงยาว 1 ครั้ง = ไม่สำเร็จ ไม่บันทึก วางให้เส้นอยู่กลางหุ่นมากขึ้น แล้วทำข้อ 1 ใหม่
  6. ปิดเครื่อง แล้วเปิดใหม่ (ไม่ต้องกดปุ่ม) หุ่นพร้อมวิ่ง ค่าถูกจำไว้ ปิดเครื่องก็ไม่หาย

ตาของหุ่น: เซนเซอร์ 5 ตัว

ใต้หัวหุ่นมีเซนเซอร์ 5 ตัว เรียงซ้ายไปขวา C0 ถึง C4 แต่ละตัวบอกได้แค่ว่าตอนนี้อยู่บน ขาว หรือ ดำ

หุ่นดูว่าเส้นดำอยู่ใต้ตัวไหน แล้วเลี้ยวเข้าหาเส้น ลองกดเซนเซอร์ด้านล่างดู

error = 0

วิ่งตามเส้นยังไง

เส้นอยู่ซ้าย ล้อขวาหมุนเร็วขึ้น ล้อซ้ายช้าลง หุ่นจึงเลี้ยวกลับเข้าหาเส้น เส้นยิ่งไกลจากกลาง ยิ่งเลี้ยวแรง

  • Kp คือความแรงในการเลี้ยวกลับ น้อยไปหุ่นหลุดโค้ง มากไปหุ่นส่าย
  • ถ้าหลุดเส้นไปทางริม หุ่นจะ หมุนตัวอยู่กับที่ จนเจอเส้นอีกครั้ง
  • ทุกครั้งที่ออกตัวจากหยุดนิ่ง หุ่นจะ ค่อยๆ เร่ง ไม่ให้หน้ายก

คำสั่งทั้งหมด

แต่ละคำสั่งมีสนามเล็กให้ดู กด เล่น แล้วดูหุ่นวิ่ง

คำสั่งที่หยุดเพราะ เห็นเส้น แม่นทุกรอบ คำสั่งที่หยุดเพราะ หมดเวลา ระยะจะเปลี่ยนตามแบต

หุ่นในเว็บเป็นหุ่นจำลอง ใช้ดูว่าคำสั่งทำอะไร ตัวเลขเวลาที่ใช้ในเว็บเอาไปใส่หุ่นจริงตรงๆ ไม่ได้

ระดับสูง: เช็คกระป๋องด้วย ultrasonic ใหม่

ระดับสูงกระป๋องสลับที่ทุกรอบ และมีเส้นแยกหลอกที่ไม่มีกระป๋อง คำสั่งกลุ่มนี้ใช้ ultrasonic (เซ็นเซอร์วัดระยะด้านหน้า ต่อ Trig = D13, Echo = D11) เช็คก่อนดัน ระดับกลางไม่ต้องใช้ กลุ่มบนใช้ได้ทั้งสองระดับ

ตั้งระยะที่นับว่ามีกระป๋องไว้บนสุดของ Mission: can_cm = 30;

สนามทดลอง

เขียน Mission เองแล้วกดรัน ใช้คำสั่งได้ทุกตัวในหน้านี้ รวมถึง speed_trun = 150; แบบกำหนดค่า และ return; เพื่อหยุดทดสอบครึ่งทาง

สนามฝึก เส้นแยกอยู่บนทางตรงหมด ภารกิจตัวอย่างดันครบ 6 ใบ สนามแข่ง (แก้ได้) วาดตามรูปสนามจริง วางเส้นแยกเดี่ยวหรือเส้นแยกคู่เองได้ แล้วกด สร้าง Mission ให้ เพื่อได้โค้ดตั้งต้น ถ้าระหว่างทางมีโค้งที่อาจหลอก FLR / FLL (โค้งขวาหลอก FLR โค้งซ้ายหลอก FLL) โค้ดจะใส่ FL_time(...) ดักไว้ข้างหน้าให้เอง เวลาที่ใส่คิดจากหุ่นจำลอง ใช้กับหุ่นจริงต้องจูนใหม่

เลือกเครื่องมือ แล้วคลิกบนเส้นสนาม ซ้าย/ขวา นับตามทิศที่หุ่นวิ่ง (ตามเข็มนาฬิกา)

ความเร็วคิดแบบเทียบส่วนจากค่าที่ 255 (240 = 240/255 ของความเร็วเต็ม) ค่า 58 คือหุ่นจำลอง หุ่นจริงวัดเองได้: ใส่ Speed_motor(255); FL_time(2000); บนทางตรง วัดระยะที่วิ่งได้ (cm) แล้วหาร 2 Speed_motor ต่ำกว่าประมาณ 100 ค่าจะไม่ค่อยแม่น ทางโค้งเยอะหุ่นจะช้าลง ให้เผื่อเวลา

    เคล็ดลับและกับดัก

    ทุกข้อมาจากหุ่นตัวนี้และการซ้อมจริง ไม่ใช่คำแนะนำทั่วไป

    1. เลือกคำสั่งที่จบด้วยเซนเซอร์ก่อนเสมอ

      FL, FLR, FLL, TL, TR หยุดตรงที่เดิมทุกรอบ ส่วน FL_time, GO, GB, R, L ระยะเปลี่ยนตามแบต ถ้ามีเส้นแยกว่างระหว่างทาง ใช้เป็นจุดอ้างอิงด้วย FLR(); cross(); แทนการวิ่งตามเวลายาวๆ

    2. แบตต่ำ = เลี้ยวไม่สุด และระยะสั้นลง เจอจริง

      ซ้อมนานแบตตก หุ่นเลี้ยวได้มุมน้อยลง คำสั่งตามเวลาไปไม่ถึง จูนและแข่งในช่วงแรงดันแบตเดียวกัน ระหว่างแข่งชาร์จได้ ชาร์จก่อนรอบจริงเสมอ และหยุดจูนเมื่อแบตต่ำกว่าช่วงนั้น

    3. push() ทำให้ความเร็วเป็น 240 ตลอดไป

      ใน push() มี Speed_motor(240) หลังดันใบแรก ค่าที่ตั้งไว้บนสุดของ Mission หายไป ถ้าช่วงหลังมีโค้งแคบแล้วหุ่นหลุด ใส่ Speed_motor(...) ใหม่หลัง can_*

    4. FL() ไม่เบรก

      FL, FLR, FLL, FL_time, cross จบแล้วล้อยังหมุนด้วยความเร็วเดิม ถ้าต้องการหยุดตรงแยก ตามด้วย cross_down() (มีเบรกข้างใน) หรือ B()

    5. เลี้ยวแล้วหุ่นเอียง? ปรับ time_cross

      cross_down ต้องพาเพลาล้อไปอยู่บนจุดแยกพอดี น้อยไป = เลี้ยวไม่ถึง ตัวเอียงเข้าเส้นแยก มากไป = เลี้ยวเกิน ลองในสนามทดลอง: แก้ time_cross แล้วดูมุมหลัง TL/TR

    6. FL() ต้องเห็นซ้ายและขวาพร้อมกัน

      ถ้าแยกสี่วางเอียงหรือหุ่นเข้าแยกเฉียง C[0] กับ C[4] อาจไม่ดำพร้อมกัน แล้ว FL() วิ่งเลยไปแยกถัดไป ให้จับแขนข้างเดียวด้วย FLL()/FLR() แทน

    7. หลุดเส้นตอน error ±1 หุ่นจะวิ่งตรงหนีไป

      หุ่นจำทิศได้เฉพาะตอนเส้นอยู่ริม (±5, ±7) ถ้าเส้นหลุดตอนอยู่เกือบกลาง (เช่นเลี้ยวมาเอียงมาก) error กลายเป็น 0 แล้ววิ่งตรง ในสนามทดลองจะเห็นได้เมื่อ TL/TR หมุนไม่สุด

    8. Speed_LR(ขวา, ซ้าย) สลับชื่อ

      คำสั่งไม่ดูเส้นเขียน speed_L ไปที่ PWMA ซึ่งคือ ล้อขวา ไม่มีผลถ้าสองค่าเท่ากัน แต่ถ้าตั้งไม่เท่ากันเพื่อแก้เบ้ ต้องจำว่าตัวแรก = ขวา

    9. ล้อเบ้: ทดสอบด้วย GO ก่อนเลือก trim เคยพลาด

      อย่าเชื่อความรู้สึกว่า "ล้อไหนช้า" ใช้ tune_trim() (GO 1.5 วิ ไม่ดูเส้น) ดูว่าหุ่นเบ้ไปทางไหน เบ้ขวา = ลดล้อซ้ายด้วย trim_L ตอนนี้ใช้ trim_L = 10, trim_R = 0 และจำไว้ว่า GO/GB ไม่ใช้ trim

    10. ทดสอบทีละท่อนด้วย return;

      ใส่ return; หลังแถวที่จะทดสอบ โค้ดข้างล่างไม่ทำงาน ไม่ต้องลบทิ้ง เขียนหนึ่งแถวต่อหนึ่งแยก และใส่คอมเมนต์ชื่อแยกไว้ท้ายแถว

    11. จบในกล่อง 20×20: เหลือที่แค่ 1 cm ยังไม่ได้ลองบนหุ่นจริง

      หุ่นยาว ~19 cm ถ้าหยุดด้วย cross_down ที่ขอบล่าง ตัวหุ่นยังโผล่นอกกล่อง ภารกิจตัวอย่างในสนามทดลองใช้วิธี: ข้ามขอบล่าง ลดความเร็ว เจอขอบบนแล้ว B() แล้ว GB() สั้นๆ ให้ทั้งคันอยู่ในกล่อง

    12. เปลี่ยนมอเตอร์ = จูนค่าตามเวลาใหม่ทั้งหมด

      time_cross, FL_time, GB, trim ทุกค่าผูกกับความเร็วมอเตอร์ชุดเดิม หลังเปลี่ยนมอเตอร์ เช็คเบ้ด้วย GO ก่อน แล้วไล่จูนจากแยกแรก

    13. กติการะดับกลางที่ต้องจำ

      ล้อต้องคร่อมเส้นตลอด หลุดเส้น = จบรอบ (ระวัง push ที่เลยปลายเส้นแยก และ GB/GO). มือแตะหุ่น = จบรอบ. กดปุ่มเริ่มได้ครั้งเดียว. ต้องออกจากจุดเริ่มภายใน 30 วิ. เข้าเส้นชัยนับคะแนนเมื่อทำภารกิจครบเท่านั้น. แข่ง 2 รอบเอารอบดีสุด มี 30 นาทีแก้โค้ดระหว่างรอบ

      จากกติกาปีที่แล้ว ตรวจกับกติกาปีนี้อีกครั้ง

    14. ก่อนอัปโหลด: กด Save ใน VS Code

      ถ้าไฟล์ .ino ยังไม่ได้บันทึก โค้ดที่อัปโหลดคือของเก่า เคยแก้ไฟล์ทับตอนที่ยังมีของไม่ได้เซฟแล้วไฟล์พัง และ error ขีดแดงใน Mission.ino เป็นของปลอม (IntelliSense) เชื่อแค่ผล compile
